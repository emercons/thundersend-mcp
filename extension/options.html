Authentication

Stable token mode keeps the same token across restarts. If the connection file leaks, the token stays valid until you regenerate or clear it. Changes apply next time the MCP server starts. The stored stable token is cleared on uninstall only while the add-on is enabled (best effort).

Send Safety

Enabled by default. While enabled, sendMail always opens a compose window for you to review; requests with skipReview: true are rejected. Disabling this lets an MCP client send mail directly without any review. saveDraft is never affected: it only writes to Drafts.
